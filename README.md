# Memory Game (Vite Version)

This version of the Memory Match Game has been updated to use Vite as its build tool, while the core gameplay remains the same. Originally built when I was learning frontend development, the game challenges users to flip and match pairs of animal cards, with difficulty levels ranging from easy to hard. It’s still powered by HTML, CSS, and JavaScript, but now benefits from Vite's faster build process and smoother development experience.
